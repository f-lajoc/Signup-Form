Problem

- After Regular deployment on github, the live link generated by github pages was showing blank for meeven after following all listed steps to add
  
Solution
- I already did all the necessary steps to make sure the page deploys using GitHub pages but i later used vercel. The first bullet point below should be ignored if you want to deploy using vercel, follow the other steps
- go to vite.config.js file, after the ``plugins: [react()],``, add ``base: "/github-repo-name-u-used"`` e.g `` base: "/signup-form",``
- then go to package.json file, after the ``"name": "app-name-u-used",``, add the website url to homepage ``"homepage": "https://urGithubName.github.io/repoName/",`` e.g ``"f-lajoc.github.io/signup-form/",``
- Then install github pages package in terminal using ``npm install gh-pages``
- then go to package.json file, create 2 scripts essential for the deployment after the ``"preview": "vite preview",``,``"predeploy": "npm run build",`` and ``"deploy": "gh-pages -d dist"``
- Then push to github
- Come back to terminal to run ``npm run deploy``
